Selected Projects

Explore my technical projects and their development.

  1. RigUp — Modular Biped Auto-Rigger

    Python / PySide6 / Autodesk Maya

    • Developing a modular Python-based auto-rigging system for humanoid characters in Autodesk Maya.
    • Automating guide placement, skeleton generation, joint orientation, and rig construction.
    • Designing the system to support animator-friendly controls and reusable rigging components.
    • Work in progress.
  2. CV Toolkit — Maya Python Tool

    Python / PySide6 / Qt Designer / Autodesk Maya

    • Developed a custom Maya tool for creating, editing, and organizing NURBS curve controls.
    • Implemented curve utilities, customizable presets, color controls, and selection tools.
    • Added offset-group creation and workflow utilities to reduce repetitive rigging tasks.
    • Designed a user interface with PySide6 and Qt Designer.
  3. Procedural OSL Halftone Shader

    Open Shading Language / Arnold / Autodesk Maya

    • Developed a procedural non-photorealistic rendering shader inspired by comic-book halftone printing.
    • Implemented screen-space dot patterns with adjustable size, rotation, contrast, and softness.
    • Used surface-normal calculations to control halftone coverage across illuminated and shadowed regions.
    • Created layered color patterns to achieve a stylized comic-book appearance.
  4. Biped Character Rig

    Autodesk Maya / Character Rigging

    • Constructed a humanoid character rig with FK/IK arms and legs.
    • Implemented FK/IK switching and matching, pole-vector controls, and foot-roll systems.
    • Developed a ribbon-based spine system with stretch and squash functionality.
    • Completed skinning and deformation refinement for the character and clothing.
  5. Mechanical Spider Rig

    Autodesk Maya / Mechanical Rigging

    • Developed a mechanical spider rig with articulated legs.
    • Implemented FK/IK leg controls and a master blending system.
  6. Procedural Gear Ratio Rig

    Autodesk Maya / Expressions

    • Developed an interconnected mechanical gear system using Maya expressions.
    • Calculated rotational relationships between gears with different tooth counts.
  7. Riggit — Creature Auto-Rigger

    Python / Autodesk Maya

    • Developing a Python-based rigging system for creature characters.
    • Exploring modular rigging workflows for non-humanoid anatomy.
    • Work in progress.
